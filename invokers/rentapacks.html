Le Grimoire des Packs

Entre le prix et le contenu d'une offre, on calcule sa rentabilité réelle : la valeur de chaque étoile, orbe ou ressource, et si le pack vaut vraiment son prix.

Ajouter un pack

Renseigne le prix payé et le contenu de l'offre. Pour les grandes quantités, tu peux écrire 1k (1 000), 2.5k (2 500) ou 1m (1 000 000).

Prix moyen par ressource

Calculé automatiquement à partir de tous les packs enregistrés : plus tu ajoutes de packs, plus l'estimation devient précise.

Méthode : quand un pack contient plusieurs types d'items, il est impossible de connaître le prix exact de chacun avec une seule offre. Le grimoire répartit le prix payé entre les items selon une estimation qui s'affine à chaque nouveau pack ajouté (technique d'allocation itérative, cohérente entre tous les packs enregistrés). Avec un seul item par pack, le calcul est une simple division — exact.

Ajouter une ressource

Ajoute ici les futures ressources du jeu (nouvelle étoile, nouvel orbe, nouvelle monnaie...) pour pouvoir les utiliser dans tes packs.

Ressources existantes

Les ressources utilisées dans au moins un pack ne peuvent pas être supprimées — supprime d'abord les packs concernés.

Réinitialisation

Efface tous les packs et ressources personnalisées enregistrés sur cet appareil.
